## Mini-Project: Tokenization Experiment
Create a tokenization experiment testing various inputs, including standard words, punctuation, whitespace, numbers, and emojis. Document the input, corresponding token count, and an analysis explaining the variance in tokenization. 

Ensure all project work is conducted on a feature branch within the `project1-learning` repository, followed by a pull request and merge.
